## 🧩 About

**Sea of Thieves Hack Menu** is a curated list of Sea of Thieves open-source tools:

- **Overlays** — on-screen helpers, layout notes, treasure radar, ship tracker
- **Quality-of-Life Helpers** — loot catalog, sail manager, overlay notes
- **Research Notes** — voyage layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Wind Indicator — visualize wind direction
- Ship Tracker — locate nearby ships for study
- Course Plotter — plan routes with map overlay
- Anchor Assist — quick anchor toggle notes

### Wallhack
- Treasure Radar — highlight nearby loot for research
- Loot Catalog — browse item types and rarities
- Map Overlay — full map with marked points

### Aimbot
- Hit Marker — visual feedback on hits
- Aim Assist — gentle aim guidance for study
- Health Bar Overlay — track player and enemy health
